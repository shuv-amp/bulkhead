# Landing page versions

Every pass of `site/index.html` is saved here as `NN-what-changed.html`. Open any file directly in a browser. `../index.html` is always the newest.

| # | File | What changed |
|---|---|---|
| 01 | `01-static-draft-three-light-scenes.html` | First static draft. Prologue hero; dark page with three light scenes (turning point, 72 hours, finale). Same as PR #10. |
| 02 | `02-pinned-scroll-scenes-counters.html` | First motion pass: pinned fullscreen scenes, fades, counting numbers. Same as PR #11. |
| 03 | `03-one-vault-carried-across-scenes.html` | One vault carried from scene to scene (drains, splits, freezes, seals) instead of separate slides. Reconstructed from the session log, so later small tweaks to this pass may be missing. |
| 04 | `04-ribbon-chapter-rail-orbits-samples.html` | Blue ribbon that follows the scroll, right-side chapter rail, items orbiting the headlines, first SAMPLE mockups. Also reconstructed, same caveat. |
| 05 | `05-own-device-per-scene-liquid-water.html` | Orbits kept only on the first three scenes; every other scene gets its own device. Ribbon redrawn as a shaded 3D tube. Water with waves, caustics and bubbles. Realistic SAMPLE mockups. |
| 06 | `06-flat-ribbon-full-code-wall-finale-dial.html` | Ribbon flat 2D, one saturated colour, round ends. Pause buttons spread evenly to every edge. Code wall fills the whole 6.9M scene. Finale filmstrip replaced by a three-minute dial around the vault. |
| 07 | `07-layered-translucent-water.html` | Diagonal light bands removed from the water. Water is now two translucent layers, each with its own wave, so it deepens where they overlap and you can see through it. Ticket boxes made solid so the line no longer shows through them. **Main line: same as `../index.html`.** |
| 08 | `08-alt-red.html` | Alternative of 07: every blue turned red (line in a strong red like Luke Baffait's), blue-grey text made neutral grey. Nothing else changed. |
| 09 | `09-alt-monochrome-film-poster.html` | Alternative of 07 in the style of *The Lobster* poster: cream paper, black ink, heavy grotesque capitals, no colour except one vermilion accent for the thing that matters (lit pause button, paid-out 2%, veto stamp, dial).
